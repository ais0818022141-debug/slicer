## 1. مقارنة سريعة: هل أستخدم ملفات CSV أم JSON؟

### هل يمكن رفع ملفات JSON إلى قاعدة البيانات؟
**نعم بالتأكيد!** تدعم منصة TealMED رفع واستيراد كلاً من:
- **ملفات CSV:** مخصصة لفرق العمل التي تفضل العمل على جداول Microsoft Excel أو Google Sheets.
- **ملفات JSON:** وهي **الخيار الأفضل والموصى به تقنياً** للنصوص الطويلة والشروحات المفصلة لعدة أسباب جوهرية:

| وجه المقارنة | ملفات CSV (`.csv`) | ملفات JSON (`.json`) [موصى به] |
| :--- | :--- | :--- |
| **سهولة التعديل** | ممتازة عبر Excel / Sheets للمبتدئين | تتطلب محرراً نصياً مثل VS Code أو Notepad++ |
| **النصوص الطويلة والأسطر المتعددة** | قد تتسبب الفواصل والأسطر الجديدة في كسر تنسيق الجدول إذا لم تُحاط بعلامات تنصيص `""` بدقة | تدعم الفقرات والأسطر المتعددة `\n` بأمان تام وبدون أي تداخل |
| **علامات التنصيص والرموز الطبية** | تكرار علامات التنصيص `""` مطلوب لمنع تلف الأعمدة | دعم أصيل للرموز والعلامات واللغات المتعددة |
| **تفنيد الخيارات الفردية** | تتطلب جمع شرح الخيارات في عمود واحد | تتيح وضع شرح خاص وتفنيد مستقل لكل خيار (`option.explanation`) |
| **السيناريو السريري (Vignette)** | يوضع كنص مجرد | يتيح تفصيل العلامات الحيوية، الفحوص المخبرية، والعمر بدقة هيكلية |

## 2. قواعد وخيارات الأعمدة ذات الخيارات المحددة (Fixed Choices / Enums)

عند تعبئة الحقول التي تحتوي على خيارات محددة، يجب الالتزام بالقيم المقبولة نظاماً لضمان عدم رفض السطر أثناء الاستيراد:

### أ) أسئلة بنك الأسئلة (Questions)
* **`difficulty` (مستوى الصعوبة):**
  - `سهل` (Easy): أسئلة استرجاع مباشر أو تشخيص كلاسيكي صريح.
  - `متوسط` (Medium - الافتراضي): أسئلة سيناريو سريري تتطلب ربط عرضين أو خطوة علاجية أولى.
  - `صعب` (Hard): حالات سريرية معقدة، تشخيص تفريقي متداخل، أو حالات فشل الخط الأول العلاجي.
* **`exam_type` (نوع الامتحان / المنهج الموجه):**
  - `usmle_step2` (أسئلة بورد وسيناريوهات سريرية Step 2 CK - الافتراضي)
  - `usmle_step1` (علوم أساسية وآليات إمراضية Step 1)
  - `board` (امتحان البورد السريري والاختصاص)
  - `national_board` (الامتحان الطبي الوطني الموحد)
* **`correct_option` (الخيار الصحيح):**
  - يقبل بالأحرف الإنجليزية الكبيرة: `A` أو `B` أو `C` أو `D` أو `E`.
  - أو يقبل بالأحرف العربية المقابلة: `أ` أو `ب` أو `ج` أو `د` أو `هـ`.
* **`points` (نقاط السؤال عند الحل الصحيح):**
  - عدد صحيح، القيمة الافتراضية المعتمدة هي `10`.
* **`is_free` (إتاحة السؤال):**
  - `1`: متاح مجاناً كعينة تجريبية لجميع المستخدمين.
  - `0`: مشفر ومخصص لمشتركي الباقة الشاملة (Pro / VIP).

---

### ب) المذكرات السريرية (Study Notes)
* **`difficulty` (مستوى صعوبة المذكرة):**
  - `سهل` | `متوسط` | `صعب`
* **`is_official` (صفة المذكرة):**
  - `1`: مذكرة رسمية معتمدة من الأكاديمية الطبية (Official).
  - `0`: مذكرة شخصية للمستخدم.
* **`is_free` (المجانية):**
  - `1` (مجانية ومفتوحة) أو `0` (مدفوعة ضمن اشتراك المادة).

---

### ج) بطاقات الاستذكار المتباعد (Flashcards)
* **`deck_title` (اسم الرزمة):**
  - اسم الرزمة الطبية (مثال: `رزمة طوارئ القلب والتظاهرات الحادة` أو `المداواة القلبية`). إذا لم تكن الرزمة موجودة مسبقاً، سيقوم النظام بإنشائها تلقائياً وربطها بالمادة والموضوع!
* **`clinical_pearl` (اللؤلؤة السريرية):**
  - قاعدة ذهبية مقتضبة تلخص جوهر البطاقة للحفظ السريع.

---

### د) القيم المرجعية المخبرية (Lab Reference Values)
* **`category` (التصنيف المخبري):**
  - `hematology` (أمراض الدم، التخثر، وأشكال الكريات)
  - `electrolytes` (الشوارد، غازات الدم الشرياني ABG، والتوازن الحمضي القلوي)
  - `metabolic` (الاستقلاب، وظائف الكلى، الكبد، والشحوم)
  - `cardiac` (الواسمات الإنزيمية والقلبية الحادة)
  - `csf` (فحص السائل الدماغي الشوكي)
  - `urinalysis` (تحليل وفحص البول)
* **صيغ المجالات (`conventional_range` و `si_range`):**
  - يكتب المجال بوضوح مع الواحدات (مثال: `13.5 - 17.5 g/dL` و `135 - 175 g/L`).

## 3. قواعد صياغة النصوص الطويلة والشروحات (Long Text & Clinical Markdown Rules)

تعتمد منصة TealMED على محرك عرض Markdown سريري مصمم خصيصاً في تطبيقي الويب والهاتف. لإخراج الشروحات والمذكرات بأعلى درجات الاحترافية البصرية، اتبع القواعد التالية:

### 1. التسلسل الهرمي للعناوين (Headings)
* استخدم `# ` للعنوان الرئيسي للمذكرة (يظهر باللون التركوازي المميز للأكاديمية وحجم خط عريض).
* استخدم `## ` للأقسام الرئيسية (يظهر بجانبه مؤشر عمودي جمالي باللون التركوازي).
* استخدم `### ` للتفريعات السريرية والفقرات الداخلية.

### 2. القوائم والنقاط (Lists)
* **القوائم النقطية:** استخدم `* ` أو `- ` في بداية السطر؛ يقوم النظام تلقائياً بتحويلها إلى نقاط تركوازية أنيقة.
* **القوائم الرقمية:** استخدم `1. ` و `2. ` و `3. `؛ يقوم النظام بتمييز الأرقام بألوان وخطوط أكاديمية واضحة.

### 3. الصناديق التنبيهية واللآلئ السريرية (Callouts & Alerts)
* **صندوق اللؤلؤة السريرية (Amber Alert):**
  ```markdown
  > 💡 **لؤلؤة سريرية (Clinical Pearl):** يرتفع التروبونين بعد 3-4 ساعات من بدء الألم ويبقى مرتفعاً حتى 10-14 يوماً.
  ```
  *(يظهر تلقائياً في خلفية ذهبية دافئة مريحة للعين).*

* **صندوق التحذير ومضادات الاستطباب (Red Warning Alert):**
  إذا احتوى الاقتباس على أيقونة `⚠️` أو كلمة `Warning` أو `تحذير`، يقوم النظام تلقائياً بتحويله إلى صندوق طوارئ أحمر:
  ```markdown
  > ⚠️ **تحذير عالي الأهمية (Warning):** تجنب إعطاء النترات أو المدرات في احتشاء البطين الأيمن لتفادي الهبوط الحاد للضغط.
  ```

### 4. التوكيد والمصطلحات الإنجليزية (Emphasis & Bold)
* استخدم النجمتين المزدوجتين `**النص**` لإبراز أسماء الأدوية، المعايير الذهبية، والمصطلحات التشخيصية الهامة.
* يُفضل وضع المصطلح الإنجليزي بجانب العربي بين قوسين في أول ذكر له، مثل: `ورم القواتم (Pheochromocytoma)`.

### 5. هيكلية الشرح المثالي لسؤال في بنك الأسئلة (Explanation Structure)
لكي يكون الشرح مكافئاً لمعايير **AMBOSS** و **UWorld**، يُنصح بتنظيمه في 3 أجزاء متسلسلة:
1. **التعليل التشخيصي المباشر:** بيان سبب صحة الخيار المختار وتفسير الآلية الإمراضية (Pathophysiology).
2. **تفنيد الخيارات المشتتة (Distractors Refutation):** فقرة تبدأ بـ `تفنيد الخيارات:` توضح باقتضاب سبب خطأ كل خيار بديل ومتى يكون هو الخيار الصحيح.
3. **الهدف التعليمي الأساسي (Educational Objective):** سطر أو سطرين يلخصان الدرس المستفاد للحفظ السريع.

## 4. طرق رفع واستيراد الملفات إلى قاعدة البيانات

تتيح لك منصة TealMED ثلاث طرق مرنة لرفع وتغذية البيانات:

### الطريقة الأولى: عبر لوحة الإدارة المتطورة (Web Admin Studio)
1. افتح صفحة الإدارة في المتصفح وسجل الدخول بحساب المسؤول.
2. انتقل إلى التبويب المطلوب (بنك الأسئلة Q-Bank، المذكرات Notes، البطاقات Flashcards، أو القيم المخبرية Labs).
3. اضغط على زر **"استيراد CSV"** واختر ملفك الجاهز، وسيقوم النظام فوراً بإنشاء المواد والمواضيع الناقصة وربط السجلات تلقائياً.

### الطريقة الثانية: عبر واجهة برمجة التطبيقات (REST API Endpoints)
يمكن استخدام واجهة Swagger التفاعلية (`http://localhost:8000/docs`) أو أدوات مثل Postman/cURL لإرسال ملفات CSV أو JSON:
* `POST /api/v1/admin/questions/import-csv` أو `POST /api/v1/admin/questions/import-json`
* `POST /api/v1/admin/notes/import-csv` أو `POST /api/v1/admin/notes/import-json`
* `POST /api/v1/admin/flashcards/import-csv` أو `POST /api/v1/admin/flashcards/import-json`
* `POST /api/v1/admin/lab-values/import-csv` أو `POST /api/v1/admin/lab-values/import-json`
* `POST /api/v1/admin/database/import` (لرفع حزمة متكاملة دفعة واحدة)

### الطريقة الثالثة: عبر أداة سطر الأوامر المباشرة (`import_seeds.py`)
موجودة داخل هذا المجلد، وتتيح لك استيراد أي ملف بضغطة زر واحدة دون الحاجة لتشغيل المتصفح:
```bash
# استيراد ملف أسئلة بصيغة JSON:
python import_seeds.py --file questions_sample.json

# استيراد ملف مذكرات بصيغة CSV:
python import_seeds.py --file notes_sample.csv

# استيراد حزمة متكاملة:
python import_seeds.py --file full_seed_bundle_sample.json
```
