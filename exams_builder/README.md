# دليل نظام تجميع دورات الامتحان الطبي الموحد (TealMED National Exam Sessions Builder)

نظام متكامل ومؤتمت لتجميع وفرز أسئلة بنوك الأسئلة الطبية حسب **السنوات والدورات الامتحانية الكاملة**، مرتبة ومقسمة بدقة متناهية إلى **كتلتين امتحانيتين** ومصنفة بحسب المواد، مع الحفاظ المطلق على سلامة الملفات الأصلية.

---

## 📌 فلسفة وهيكلية توزيع الكتل الامتحانية

تمت برمجة النظام ليعكس التوزيع والنمط المعتمد في الامتحان الوطني الطبي الموحد:

### 🔹 الكتلة الأولى (Block 1):
1. **أمراض الباطنة والداخليات**:
   - القلبية (`cardio`)
   - الهضمية (`gastro`)
   - الصدرية (`pulmo`)
   - الدم / الدموية (`hema`)
   - الغدية (`endo`)
   - المفاصل والرثوية (`rheuma`)
   - الكلية (`renal`)
   - الأمراض الخمجية (`infectious` - مدعومة تلقائياً عند إضافتها)
   - الداخلية العصبية (`neuro_internal` - مدعومة تلقائياً عند إضافتها)
   - الطب النفسي (`psychiatry` - مدعوم تلقائياً عند إضافته)
2. **طب الأطفال**:
   - طب الأطفال 1 (`peds1`)
   - طب الأطفال 2 (`peds`)
3. **الأمراض الجلدية**:
   - الجلدية (`derma` - مدعومة تلقائياً عند إضافتها)

---

### 🔸 الكتلة الثانية (Block 2):
1. **النسائية والتوليد**:
   - النسائية (`gync`)
   - التوليد (`obs`)
2. **الجراحات**:
   - الجراحة العامة (`general_surgery`)
   - الجراحة العظمية (`orthopedics`)
   - الجراحة البولية (`urology`)
   - الجراحة الصدرية (`thoracic_surgery`)
   - جراحة الأطفال (`ped_surgery`)
   - الجراحة العصبية (`neurosurgery`)
   - الجراحة التجميلية (`plastic`)
   - الجراحة القلبية (`cardiac_surgery`)
   - جراحة الأوعية (`vascular_surgery`)
   - جراحة الأورام (`onco`)
3. **الأذنية**:
   - الأذنية (`ent`)
4. **العينية**:
   - العينية (`optho`)

## 🛡️ مبدأ حماية وعزل البيانات (Safety Guarantee)

- مجلد العمل `exams_builder/` معزول تماماً ومستقل.
- يحتوي المجلد على نسخة لقطة عمل `input_snapshot/` يتم العمل عليها وقراءتها فقط.
- **ملفات مجلد `final/` لا يتم تعديلها أو الكتابة عليها أو حذف أي ملف منها نهائياً.**

---

## 🚀 كيفية الاستخدام وإعادة البناء مستقبلاً

عند إضافة أي مواد ناقصة (مثل الجلدية أو الخمجية أو العصبية) أو تعديل/إضافة أسئلة في `final/`:

### الطريقة الأسهل (بضغطة زر):
1. قم بتشغيل الملف **`build_sessions.bat`** الموجود في المجلد الرئيسي (أو `exams_builder/run_builder.bat`).
2. اختر الخيار **[1] مزامنة وبناء كافة الدورات**.
3. سيقوم البرنامج فوراً بما يلي:
   - فحص المجلدات الجديدة في `final/`.
   - أخذ لقطة محدثة منها إلى `input_snapshot/`.
   - قراءة كافة الأسئلة وإعادة تجميع الدورات وفرزها.
   - إنشاء ملفات JSON و CSV و HTML جديدة ومحدثة.
   - فتح لوحة التحكم `index.html` في المتصفح.

### عبر موجه الأوامر (CLI):
```bash
# بناء مع مزامنة أحدث الملفات من final
python exams_builder/build_exam_sessions.py --sync

# بناء من لقطة العمل الحالية
python exams_builder/build_exam_sessions.py
```

## 📂 صيغ المخرجات (Output Formats)

لكل دورة امتحانية (مثال: دورة أيار 2026، دورة تشرين 2024، دورة آذار 2023... إلخ):

1. **صيغة JSON (`output/json/دورة_XXX.json`)**:
   - مصفوفة أسئلة مرقمة تسلسلياً (1 إلى N).
   - كل سؤال مزود بـ `block_id`، `block_name`، `category_name`، `subject_name`.
   - كامل الخيارات، الإجابة الصحيحة، التعليل السريري، وتفنيد الخيارات، والملاحظات عالية الأهمية.
   - إحصائيات دقيقة في ترويسة الملف لعدد الأسئلة في الكتلة 1 والكتلة 2 وتوزيع المواد.

2. **صيغة CSV (`output/csv/دورة_XXX.csv`)**:
   - متوافقة 100% مع Microsoft Excel وبترميز عربي كامل بدون أي تشويه (`UTF-8-SIG`).
   - أعمدة مصنفة: `Question_Number`، `Block`، `Block_Category`، `Medical_Subject`، `Chapter_or_Section`، `Question_Text`، `Correct_Answer`، `Option_A` إلى `Option_F`، `Explanation`، `High_Yield_Note`... إلخ.

3. **صيغة HTML التفاعلية (`output/html/دورة_XXX.html`)**:
   - واجهة طبية راقية بتصميم مخصص (Alexandria & IBM Plex Sans Arabic).
   - ترويسة متقدمة بها:
     - أزرار فلترة فورية: الكل، الكتلة الأولى، الكتلة الثانية، أو أي مادة منفردة.
     - مربع بحث لحظي في نص الأسئلة والخيارات.
     - زر إظهار/إخفاء كافة الإجابات الصحيحة.
     - زر إظهار/إخفاء كافة الشروحات الطبية والتفنيد.
     - زر تبديل الوضع الليلي / الفاتح (Dark / Light Mode).
     - زر طباعة منسق للتصدير المباشر كـ PDF من المتصفح (Print -> Save as PDF).
   - إمكانية الضغط التفاعلي على أي خيار لاختبار الذات (يتحول للأخضر عند الصحة وللأحمر عند الخطأ).

4. **لوحة التحكم والفهرس الشامل (`output/index.html`)**:
   - بوابة مركزية تعرض جميع الدورات المفهرسة مع إحصائياتها وروابط تصفحها أو تحميلها.
